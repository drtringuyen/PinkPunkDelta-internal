Procreate files

Tap Get PSD, then open the download with Procreate. Paint on SHD and TEX. More layers: group them and name the group SHD or TEX.
One time: the “Send to Blender” Shortcut
  1. Copy this address:
  2. Shortcuts app → +, name it Send to Blender. In Details turn on Show in Share Sheet and receive Images and Files.
  3. Add Get Contents of URL, paste the address. Show More: Method POST, Request Body Form, add a File field, key file, value Shortcut Input.
  4. Add Show Notification with Contents of URL.
Then in Procreate: Actions → Share → PSD → Send to Blender. A PNG works too when its canvas is named SHD_… or TEX_… plus the object's name.
